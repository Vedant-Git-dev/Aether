# Aether Mistral Provider

Official Aether provider plugin for Mistral models, Voxtral transcription, and
Mistral memory embeddings.

Install from Aether:

```bash
aether plugins install @aether/mistral-provider
aether gateway restart
```

Set `MISTRAL_API_KEY`, then select a `mistral/*` model or configure Mistral for
media transcription, realtime transcription, or memory embeddings.

See <https://docs.aether.ai/providers/mistral> for setup and configuration.
