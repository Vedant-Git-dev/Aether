# Aether Feishu/Lark

Official Aether channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from Aether:

```bash
aether plugins install @aether/feishu
```

Configure the Feishu/Lark app credentials in Aether, then connect the plugin to the chats where agents should receive and send messages.
