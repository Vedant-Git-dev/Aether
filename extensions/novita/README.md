# Aether NovitaAI provider

Official Aether provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
aether plugins install @aether/novita-provider
aether gateway restart
```

## Docs

See `docs/providers/novita.md` in the Aether repository, or the published
docs at `https://docs.aether.ai/providers/novita`.
