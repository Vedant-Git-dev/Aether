# Aether Vydra Provider

Official Aether provider plugin for Vydra image, video, and speech generation.

Install from Aether:

```bash
aether plugins install @aether/vydra-provider
aether gateway restart
```

Set `VYDRA_API_KEY`, then configure an image, video, or speech model. See
<https://docs.aether.ai/providers/vydra> for capability details and examples.
