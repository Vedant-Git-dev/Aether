# Aether BytePlus Provider

Official Aether provider plugin for BytePlus model inference and Seedance
video generation.

Install from Aether:

```bash
aether plugins install @aether/byteplus-provider
aether gateway restart
```

Set `BYTEPLUS_API_KEY`, then select a `byteplus/*` or `byteplus-plan/*` model.

See <https://docs.aether.ai/concepts/model-providers#byteplus-international>
for model setup and <https://docs.aether.ai/tools/video-generation> for
Seedance video generation.
