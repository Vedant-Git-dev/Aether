# Vercel AI Gateway Aether provider

Official Aether provider plugin for Vercel AI Gateway.

## Install

```sh
aether plugins install @aether/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the Aether repository, or the published docs at `https://docs.aether.ai/providers/vercel-ai-gateway`.
