# Aether Volcengine Provider

Official Aether provider plugin for Volcengine models, the Volcengine coding
plan, and Volcengine Speech text-to-speech.

Install from Aether:

```bash
aether plugins install @aether/volcengine-provider
aether gateway restart
```

See <https://docs.aether.ai/providers/volcengine> for model and speech setup.
