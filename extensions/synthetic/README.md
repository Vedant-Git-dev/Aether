# Aether Synthetic Provider

Official Aether provider plugin for Synthetic's hosted Anthropic-compatible
API.

Install from Aether:

```bash
aether plugins install @aether/synthetic-provider
aether gateway restart
```

Configure `SYNTHETIC_API_KEY`, then select a `synthetic/<model-id>` model.

See https://docs.aether.ai/providers/synthetic for model and configuration
details.
