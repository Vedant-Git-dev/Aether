# OpenCode Zen Aether provider

Official Aether provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
aether plugins install @aether/opencode-provider
aether gateway restart
```

## Docs

See `docs/providers/opencode.md` in the Aether repository, or the published
docs at `https://docs.aether.ai/providers/opencode`.
